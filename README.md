# Blockyard Essentials

Public client downloads and automatic update files for Blockyard Essentials.

[Installation instructions](https://blockyard-voice.playit.plus/play) · [Prism pack](https://rattahamberg.github.io/blockyard-essentials/Blockyard-Essentials-Prism.zip) · [Manual Modrinth pack](https://rattahamberg.github.io/blockyard-essentials/Blockyard-Essentials.mrpack)

The Prism pack checks the published mod list before each launch. Personal settings and worlds are preserved. Minecraft and Fabric versions stay fixed to the instance's compatibility channel.

Upstream mods are downloaded from their original providers with pinned hashes. Bundled installer licenses are included in the Prism ZIP under minecraft/blockyard-licenses. SHA256SUMS lists checksums for the current release artifacts.
